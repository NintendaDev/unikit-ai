## Gate calibration

| gate | reachable | what proves it |
|---|---|---|
| structural | no | no affordance reads scene content in any form through this server; the only structural verification available bypasses it entirely, reading the scene file's own text directly |
| compile | partly | only inside a live session started through this server — no diagnostic surface exists before or outside one |
| console | partly | the same run-gated surface as compile, tied to nothing narrower than the whole session |
| runtime | yes | a live session together with its own status and log read — the one path confirmed unaffected by the report-vs-outcome defect that touches most of this server's other calls |
| playtest | no | no input or simulation affordance exists |
| visual | no | no screen capture exists in any form — neither of the editor nor of a running session |

`GATE LIFTED` is not pre-declared here. Unreachability is established by a run:
you tried, the affordance is absent, you produced the evidence of its absence —
only then is the gate lifted, and with a reason.
