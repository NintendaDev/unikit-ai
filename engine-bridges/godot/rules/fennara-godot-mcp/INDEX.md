# Fennara Godot AI

Reference for ordinary use — Context7 `/fennaraofficial/fennara-godot-ai`.
**This file is an amendment to it.** Take signatures from the server, not from
the reference and not from here.

## Access

Several catalogs describe this server and no single one of them contains all the
rest: the protocol listing, the server's own status report, and two registries
inside the editor bridge. They disagree in both directions — the status report names an
affordance the protocol path refuses to run, and the bridge reaches affordances
the protocol listing never mentions. Absence from your list is therefore not
evidence that a capability is missing, and presence in a self-report is not
evidence that it is callable. The only test is the attempt.

The listing is not a rights boundary either. What it leaves out is reachable by
other routes on the same machine, under the same credential, with no approval
anywhere on the path. Treat it as a description of one door, not of the building.

The approval mode the editor offers belongs to the editor's own assistant and
does not touch this channel. Do not read it as a restriction on your calls, and
do not go looking for an unlock step — there is none.

## Live failure classes

| class | what it turns into |
|---|---|
| false success | done reported over a wiring that never reached the file |
| catalog phantom | a listing that names what will not run, and is silent about what will |
| lying validator | a structural check that passes over a project that cannot start |
| opaque aggregate | a structure read that folds neighbours away and takes their children with them |
| stale read | a truncation notice dropped on the way to you |

The detector for each of these in `dev-principles` is mandatory here. A class may
have been fixed since it was measured — the detector settles that, this table does not.

`fake rollback` is not live here, and that is worse rather than better: see Irreversible.

## Shape and cost

There is no delta gate: no fingerprint, no revision tag, no change counter. Build
the delta from a marker of your own.

Reference reading has no ceiling and its cost grows toward the root of the class
hierarchy: a leaf widget costs a few thousand characters, the base class it
inherits from costs eighty thousand, and three base classes in one call cost over
two hundred thousand. No budget is applied to it, and the server's own contract
makes this read the mandatory first step of every editing cycle. Ask for the leaf
you are working with.

Structure comes back at about forty characters per node, and neighbours whose
names differ only by a trailing number are folded into one summarised row from two
neighbours upward — every descendant of every folded node gone from the answer,
and no marker where they were. Compare the node count the answer declares against
the rows it actually printed.

The escape hatch is the main interface here, not the fallback: one call carries a
whole batch, and its own contract is the longest description in its catalog.

## Check

| id | area | confirm that |
|---|---|---|
| scene-1 | scene | the structure read was complete: the declared node count matches the rows returned, and a folded row took the descendants of everything it folded |
| scene-2 | scene | the handler wiring survived the save: reading the connection back inside the same worker confirms only the graph held in memory |
| scene-3 | scene | after a structural edit of an inherited scene, the nodes you added earlier are still there and what you deleted is actually gone |
| scene-4 | scene | after renaming a serialized field, the old value left the scene: the declarations and the stored properties are shown side by side and are not compared for you |
| scene-5 | scene | the scene was not saved when the report says the run failed: a validation failure of a saved scene is a failure taken after the write |
| asset-1 | asset | a scene or resource written as raw text went through the engine: that route produces neither diagnostics nor validation |
| compile-1 | compile | the launch preflight saw what is actually there: an autoload pointing at a missing file does not enter its count |
| compile-2 | compile | the structural check descended into what the scene instances: a clean verdict covers the scene itself and nothing it embeds |
| console-1 | console | the error you read belongs to your run: a snapshot of the editor panel may belong to no run at all |

## Irreversible

There is no rollback here in any form — no step, no snapshot, no anchor. One
exception: changing import settings is a real transaction, staged and restored
when its own check fails. Version control is the only rollback; anchor before the
phase that writes.

Removal calls inside the escape hatch name nothing before they act and ask for no
confirmation. Enumerate what you are about to remove yourself.

## Lane

One executor per editor instance, and a live run session is narrower still: the
contract declares it single across the machine. What a second attempt does was
not measured here — find out by trying, and do not assume it queues.

## When this file is silent

Two reasons to ask the reference:
— an unfamiliar area — what approaches the authors propose (once per area per session);
— a dead end — the schema is there, the capability is not.

The reference describes **intent, not behaviour**. What you take from it carries the
same evidence obligations.

This server also ships a corpus of its own instructions into the project and appends
a block to the root agent file. That corpus is about its API and is maintained with
the server. This file is about the places where its reports and its state disagree.
