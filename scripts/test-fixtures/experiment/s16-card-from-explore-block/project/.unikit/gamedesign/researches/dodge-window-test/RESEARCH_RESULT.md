# A short slow-motion window after a perfect dodge

## Active Summary

<!-- unikit:active-summary:start -->
Goal: learn whether a short slow-motion window after a perfect dodge makes fights feel skillful rather than confusing.
Scope: the first three enemy types of one arena. Not covered: sound, rewards, later arenas.
Constraints: no new controls; the window must not change the damage of any enemy.
Decisions: DEC-1 — the window lasts about half a second; DEC-2 — only a perfect dodge opens it; DEC-3 — a screen tint shows that the window is open.
Risks: RISK-1 — players read the slow motion as lag; RISK-2 — veterans stop dodging early and wait for the window.
Open questions: OQ-1 — how many fights a tester needs before the window feels normal; OQ-2 — whether the tint should fade in; OQ-3 — a longer window with a counter-attack bonus is left for a later experiment.
Success signals: testers can say when the window opened; they describe the dodge as their own skill; nobody calls it lag.

## Conclusions

DEC-1 — the window lasts about half a second, because it has to be long enough to see and short enough not to stall the fight. This is an assumption until it is played.
DEC-2 — only a perfect dodge opens it, because a reward for any dodge stops rewarding precision.
DEC-3 — a screen tint shows that the window is open, so that a tester can tell it from lag.

RISK-1 — players read the slow motion as lag when the picture also stutters.
RISK-2 — veterans stop dodging early and wait for the window, so the reward changes the way they play.

## Findings

F-1 — A short slow motion after a precise defensive move is a familiar way to make a timing success visible. It is an assumption that it works here; no study of the game's own players was made.
F-2 — A tint or a sound is the usual way to say that a special state is on. Without it, testers tend to describe an effect they cannot name as a fault.
F-3 — The first three enemy types attack in clear, readable patterns, so a perfect dodge is possible against each of them.

## Open Questions

OQ-1 — how many fights a tester needs before the window feels normal.
OQ-2 — whether the tint should fade in.
OQ-3 — a longer window with a counter-attack bonus.
