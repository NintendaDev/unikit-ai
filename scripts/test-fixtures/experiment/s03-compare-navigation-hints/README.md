# Scenario 3 — compare three navigation hints

## Scenario
The designer writes: "Compare three ways to show the player where to go: an arrow, a glowing path and a map marker."

## Setup
No saved experiments.

## Expected
- The request is read as one question with three variants, not as a search for ideas.
- One experiment with three variants that differ by a single factor: the form of the hint.
- The card lists the parameters that switch between the variants and how the tester switches them, as a requirement of the card.
- The draft is printed and approved before anything is written.

## Must not
- Create three separate experiments.
- Change another factor between the variants.
- Name engine classes, code files or architecture.
