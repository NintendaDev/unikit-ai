# Scenario 13 — a quick pass for a small idea

## Scenario
The designer writes: "Think through an experiment for a hint arrow in the first room."

## Setup
No saved experiments. A GDD may or may not exist. Web tools may be present; the pass must not use them.

## Expected
- One question about the depth of the pass, asked after a printed line that says what each answer gives; for a small idea the quick pass is the recommended answer, with the reason in a clause.
- A frame: the decision the designer will take after the test and two to four qualities the test is read against, asked once; the qualities become `Judged on:` and are not asked again later.
- Two or three options for the main choice, each with its gain and its price, one marked Recommended with the reason; the designer chooses.
- How the test could mislead, in concrete terms: the outside factor, the sign an observer would see, what lowers the risk.
- A card that ends with a Rationale built from the pass: why the design, the options set aside, the intended feeling, what a failure would teach.
- No web query and no notes file; `Based on:` stays `none`.
- Nothing is written before the designer approves.

## Must not
- Search the web or write a notes file in a quick pass.
- Ask for the judged qualities a second time after the frame.
- Offer more than four options, or none marked Recommended.
- Leave the Rationale empty or fill it with reasons that were not discussed.
- Write to the experiment store before approval.
