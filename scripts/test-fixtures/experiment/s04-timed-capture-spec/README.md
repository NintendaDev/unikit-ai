# Scenario 4 — a full specification for a timed capture

## Scenario
The designer writes: "Write a full specification: capture the flag against a timer. Hypothesis: a visible countdown raises the pace of play."

## Setup
No saved experiments.

## Expected
- A card with all fourteen sections of the template, in the designer's words.
- The player can see the goal, progress, success, failure and the next action.
- Any threshold is labelled a preliminary acceptance target; the duration is not forced to five minutes.
- The card is independently understandable and is marked Ready for Planning only if the checklist holds.

## Must not
- Name engine classes, code files, architecture or dependency injection.
- Refer to the conversation ("as discussed").
- Invent measured numbers.
