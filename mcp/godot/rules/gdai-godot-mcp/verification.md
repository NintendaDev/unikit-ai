## Gate calibration

| gate | reachable | what proves it |
|---|---|---|
| structural | yes | the aggregate structural read: strong and honest on the scene it was handed, explicit about count-based truncation and honest about depth-based truncation. A page cursor works only once the read is already narrowed to the right starting point |
| compile | partly | a real scene run this session, not the act of opening a script for inspection — the error report stays silent about a static script error and about broken autoloads until the scene has actually run once |
| console | partly | the same run-gated report as compile — nothing in it is tied to one particular session or one particular change on its own |
| runtime | yes | a live play session together with the same error report read inside it — both a static and a runtime fact surfaced together, backed by an actual run |
| playtest | partly | an input-simulation affordance is present in the catalog with a real, non-degenerate schema, but this run did not exercise it live — treat as unconfirmed, not as reachable, until a live call closes the claim |
| visual | partly | an editor-window screenshot arrived and was read as an image; a running-scene screenshot timed out on the one attempt made, immediately after entering play mode |

`GATE LIFTED` is not pre-declared here. Unreachability is established by a run:
you tried, the affordance is absent, you produced the evidence of its absence —
only then is the gate lifted, and with a reason.
